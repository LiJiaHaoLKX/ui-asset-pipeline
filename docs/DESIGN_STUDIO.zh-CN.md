# 项目设计规范向导

项目设置提供：基础问答、最多五张参考图、文本模型生成规范、图片模型生成样式预览、自然语言调整和人工确立。

## 数据与生效范围

- `workspace/design-studio/studio.json` 保存项目级问答、参考图索引、版本列表、当前草稿和已确立版本。
- `workspace/design-studio/images/` 保存参考图及每次预览，通过仅本机 API 读取；不开放 workspace 整个目录。
- `workspace/design-studio/runs/` 每次调用独立记录，文本模型请求日志隐藏图片数据，均不记录 API 密钥。
- `workspace/design-studio/adoptions/` 保存确立前后的规范备份。
- 只有“确立项目规范”才写入现有正式设计规范路径。已有页面和 Codex 任务快照保持不变。
- 每次生成规范都会创建新的独立文本模型请求和新的运行目录；请求不携带上一版规范、上一版预览或其他历史消息。版本历史只用于本地查看，不会形成模型会话上下文。

## 生成契约

文本模型只接收当前问答、当前选中的参考图和本次自然语言意见，每次请求均从空白会话开始。返回中文说明、专业 spec JSON、英文预览提示词。验证配色、字体、间距、圆角、组件、素材规则和画布后保存新版本。

图片模型使用图片 API 地址和密钥，模型 ID 单独配置（默认 `gpt-image-2.5`，兼容中转站别名）。请求尺寸为 1024×1536 的规范样式板，固定 n=1。参考图先由文本模型归纳成规范和提示词；图片生成接口接收规范与提示词，不直接上传参考图。样式板不代替规范里的项目画布。

同一项目同时只运行一个规范任务。修改问答或参考图后旧版本不能确立，必须重新生成。每个新规范版本必须生成自己的预览才能确立。配置保存按钮只保存 API 配置，不再隐式保存旧的规范编辑器内容。

图片预览与页面生成共用生成锁，串行调用。`task.json` 保存最近任务状态，刷新设置页可继续等待；服务重启中断的任务提示重新生成。参考图移除仅取消选择，保留历史版本引用的文件。向导工作目录已加入 Git 忽略规则。

所有文本模型和视觉分析请求统一使用 OpenAI 兼容接口的 `stream: true`。服务端逐条消费 SSE、记录脱敏的流事件并拼接最终文本，再执行 JSON 校验；图片生成接口仍使用原有非流式图像接口。流式连接被关闭时会自动重试并保存诊断。

## 验收

保存问答 → 上传参考 → 生成规范 → 查看 JSON 与说明 → 生成预览 → 输入反馈 → 新规范及新预览 → 确立。每步错误在向导内显示。已有规范始终可在下方只读区域查看。真实模型调用由用户在浏览器确认；开发验证使用模拟响应。
